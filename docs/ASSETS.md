`product-illustration.svg` is an original generic market-package illustration for six additional demo products. `favicon.svg` is a locally authored grid mark. The UI uses Lucide icons rather than exported vectors. DM Sans was read from Figma's typography inspector (14 px / bold on the inspected product label), then installed from `@fontsource-variable/dm-sans`; its font license is included in the dependency. Login's serif accent uses Georgia as an approximation.

The thumbnails are native 2× exports of 54 px Figma image layers. They are adequate for reference-sized cards but not high-resolution storefront photography. Assets belong to the supplied project; no third-party stock image search was used.
